# Contact Cards – React

A React-based Contact Card application that allows users to enter contact details and dynamically display them as reusable contact cards.

## Features

- Add a new contact using a form
- Display contacts dynamically
- Reusable Contact Card component
- Delete contacts
- Form validation
- Responsive design
- Clean and modular React component structure

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- Vite

## React Concepts Used

- useState Hook
- Props
- Event Handling
- Component Reusability
- Conditional Rendering
- Array map()
- Dynamic Rendering
